# EazyChise 🍜☕
> **"Platform Franchise F&B Cerdas untuk UMKM Indonesia"**

EazyChise adalah platform digital revolusioner yang dirancang khusus untuk mendemokratisasi akses ke bisnis franchise F&B bagi UMKM dan investor pemula di Indonesia. Kami menggabungkan data terkurasi dengan kecerdasan buatan (AI) untuk memastikan setiap langkah investasi Anda didasarkan pada data yang akurat, aman, dan transparan.

---

## 🎯 Latar Belakang & Masalah (Problem Statement)
Industri F&B (Food and Beverage) merupakan salah satu sektor bisnis paling menjanjikan di Indonesia. Namun, data menunjukkan tingginya angka kegagalan bagi pelaku UMKM baru, khususnya di tahun pertama mereka merintis bisnis. Beberapa masalah utama yang sering dihadapi meliputi:

1. **Minimnya Transparansi Data:** Calon mitra kesulitan mencari informasi objektif mengenai performa asli suatu brand franchise. Banyak janji manis "cepat balik modal" tanpa rincian angka yang masuk akal.
2. **Kalkulasi Finansial yang Melenceng (BEP/ROI):** Kebanyakan pengusaha pemula tidak menghitung biaya operasional tersembunyi (seperti royalti bulanan, penyusutan alat, inflasi bahan baku), sehingga estimasi Break Even Point (BEP) meleset jauh.
3. **Salah Pilih Lokasi:** Pemilihan lokasi seringkali hanya mengandalkan "insting" atau harga sewa murah, tanpa analisis kepadatan penduduk, demografi, atau analisis kompetitor di sekitar.
4. **Kebingungan Menentukan Brand yang Cocok:** Dengan ratusan brand F&B yang ada, pemula sering kali terjebak FOMO (Fear Of Missing Out) mengikuti tren sesaat alih-alih memilih kemitraan yang sesuai dengan profil risiko, passion, dan modal mereka.

---

## 💡 Solusi dari EazyChise
EazyChise hadir bukan sekadar sebagai direktori franchise, melainkan sebagai **Ekosistem Pintar dan Konsultan Bisnis Pribadi** yang menyediakan solusi nyata atas masalah di atas:

1. **Kurasi Ketat 47-Poin:** Semua brand franchise yang masuk dalam platform EazyChise telah melewati validasi ketat, baik dari sisi legalitas, rekam jejak, kesehatan finansial, hingga standar kualitas (SOP).
2. **AI Advisor & Kalkulator Cerdas:** AI kami bertindak layaknya analis keuangan yang membantu pengguna melakukan simulasi laba rugi secara akurat dan personal.
3. **Analisis Lokasi Berbasis Peta:** Integrasi kecerdasan spasial untuk merekomendasikan titik lokasi terbaik bagi kategori franchise yang dipilih.
4. **Sistem Terpadu & Transparan:** Memudahkan calon mitra membandingkan brand secara *apple-to-apple* dalam satu genggaman, dari mulai modal awal, dukungan pasca-pembelian, hingga review asli mitra lain.

## ✨ Panduan Fitur & Langkah Penggunaan (Step-by-Step)

### 1. 🤖 AI Franchise Advisor (Konsultan Bisnis Pribadi)
Asisten cerdas ini akan menganalisis profil Anda dan memberikan rekomendasi brand yang paling ideal.
* **Cara Penggunaan:**
  1. Klik tombol **"Tanya AI Advisor"** (ikon berkilau di sudut kanan bawah) pada website.
  2. Jawab 4 pertanyaan panduan singkat: Modal yang disiapkan, Lokasi target, Pengalaman bisnis, dan Kategori F&B favorit.
  3. Berikan informasi tambahan (opsional) pada form teks bebas (misal: "Saya ingin bisnis yang bisa ditinggal sambil kerja kantoran").
  4. Klik **"Analisis Sekarang"**. Dalam hitungan detik, AI akan memproses algoritma dari ratusan data dan menyajikan rekomendasi terbaik lengkap dengan analisis SWOT, estimasi ROI, dan langkah mitigasi risiko.

### 2. 📊 Smart BEP & ROI Calculator (Kalkulator Finansial)
Alat canggih untuk mensimulasikan arus kas dan mengukur seberapa realistis proyeksi balik modal suatu franchise.
* **Cara Penggunaan:**
  1. Akses menu **"Analisis BEP"** atau klik "Hitung BEP" pada halaman detail franchise pilihan.
  2. Masukkan asumsi pendapatan (Harga jual rata-rata & target penjualan per hari).
  3. Masukkan struktur biaya (Modal awal & Harga Pokok Penjualan/HPP).
  4. Tambahkan rincian Biaya Operasional Tetap (Sewa tempat, gaji karyawan, listrik, royalti).
  5. Hasil akan secara instan ditampilkan dalam bentuk visual grafik Break Even Point, Laba Bersih per bulan, Durasi Balik Modal (ROI), serta kesimpulan apakah skenario bisnis tersebut "Aman", "Berisiko", atau "Sangat Cuan".

### 3. 🔍 Katalog Franchise Terkurasi & Comparison Tool
Akses eksklusif ke berbagai opsi kemitraan berkualitas, dari modal kecil di bawah Rp 5 Juta hingga skala resto kelas premium.
* **Cara Penggunaan:**
  1. Masuk ke menu **Katalog Franchise**.
  2. Manfaatkan fitur **Filter Cerdas** untuk menyortir pencarian Anda secara spesifik berdasarkan rentang modal awal atau kategori kuliner.
  3. Klik *card* brand untuk melihat detail komprehensif, mulai dari rincian syarat kemitraan, apa saja yang didapat, hingga galeri foto nyata dari gerai mitra.
  4. Gunakan fitur **Bandingkan Brand** dengan memilih 2 hingga 3 nama franchise sekaligus untuk melihat secara *side-by-side* selisih modal awal, durasi balik modal, keuntungan, dan dukungan yang akan didapat.

### 4. 🗺️ AI Location Recommender (Rekomendasi Lokasi Cerdas)
Fitur peta pintar interaktif untuk menemukan titik *hotspot* berjualan yang ramai tanpa perlu membayar jasa survei lapangan.
* **Cara Penggunaan:**
  1. Buka dashboard peta pada bagian fitur **Pencari Lokasi**.
  2. Pilih jenis kategori bisnis yang akan Anda buka (misalnya: "Kedai Kopi" atau "Makanan Cepat Saji").
  3. Sistem akan otomatis memindai dan memvisualisasikan peta di area target. Indikator "Heatmap" akan menampilkan wilayah dengan kepadatan trafik tinggi (seperti area perkantoran atau kampus).
  4. Hindari area merah yang memiliki terlalu banyak kompetitor sejenis, dan incar area **Hotzone Hijau** yang padat populasi namun persaingannya rendah.

### 5. 📄 Official Proposal Generator
Fitur untuk mengunduh berkas lengkap penawaran guna keperluan presentasi bisnis dengan calon investor atau keluarga.
* **Cara Penggunaan:**
  1. Pada halaman detail sebuah franchise, scroll ke bawah dan temukan tombol **"Download Proposal Resmi"**.
  2. Sistem akan menghasilkan (generate) dokumen PDF resmi secara dinamis berisi informasi terbaru dari franchisor, proyeksi ROI, profil perusahaan, hingga detail kontak kemitraan.

- **Animasi & Interaktivitas**: Framer Motion, CSS Keyframes (Scroll-reveal, Micro-interactions)
- **Icons**: Lucide React, React Icons
- **State Management**: React Hooks & Context API

## 🚀 Panduan Instalasi Lokal

Untuk menjalankan aplikasi ini secara lokal di perangkat Anda:

```bash
# 1. Clone repositori proyek
git clone https://github.com/username/eazychise.git

# 2. Masuk ke dalam direktori proyek
cd eazychise

# 3. Install seluruh dependencies yang dibutuhkan
npm install

# 4. Setup Environment Variables
# Buat file baru bernama `.env.local` di root direktori dan tambahkan kunci API Gemini:
GEMINI_API_KEY=your_gemini_api_key_here

# 5. Jalankan development server
npm run dev
```
Setelah server berjalan, buka tautan `http://localhost:3000` di web browser Anda untuk melihat hasilnya.
